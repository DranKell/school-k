# Публикация сайта на GitHub Pages

В папке — готовый одностраничный сайт (`index.html`) и эта инструкция.

## GitHub Pages (бесплатно)
1. Создайте репозиторий на github.com (например `skchi-chusovoy-site`).
2. Загрузите `index.html` в корень репозитория.
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Сайт будет доступен по адресу `https://<user>.github.io/<repo>`.

## Другие варианты публикации

### Netlify
1. Зарегистрируйтесь на netlify.com, перетащите папку с сайтом в Netlify Drop.
2. При необходимости настройте собственный домен в Domain settings.

### Vercel
Импортируйте проект и при необходимости настройте собственный домен в Settings → Domains.

## Как редактировать
- Все тексты — прямо в `index.html`, разделы помечены комментариями (`<!-- РАСПИСАНИЕ -->` и т.д.).
- Заглушки таблицы расписания, состава и галереи замените реальными данными.
